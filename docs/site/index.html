Run FreebieHarbor in Docker.

The prebuilt Linux amd64 image needs only Docker and a persistent volume. No database server, AI subscription or setup wizard.

docker volume create freebieharbor-data
docker run -d --name freebieharbor --restart unless-stopped \
  -p 127.0.0.1:18081:8080 \
  -v freebieharbor-data:/data \
  ghcr.io/bl0ck154/freebieharbor:v0.4.3

Local-only by default. Open http://127.0.0.1:18081 on the host. On a remote server, use an SSH tunnel. The dashboard has no built-in login, so do not expose it directly to the internet.

What it is — and what it isn't.

✓ A giveaway discovery hub

Find public free-game offers, remember claimed ones and optionally get notified. You control the server and storage.

✕ Not an auto-claim bot

FreebieHarbor doesn't enter contests, redeem games or guarantee prizes. Site access, key stock and regional availability can vary.

Frequently asked questions

Is FreebieHarbor free?

Yes. The software is free and open source under the MIT license. Running your own server may have infrastructure costs.

Does it require my Steam password?

No. Public offer discovery works without a Steam account. SteamGifts and ASF statistics are optional read-only integrations using data snapshots.

Can it automatically claim free Steam games?

No. It tracks offers and lets you mark them claimed. It does not log in to stores or submit contest entries.

What are the supported sources?

GamerPower, FreeToKeep, GG.deals RSS and best-effort Alienware Arena. Additional provider availability depends on their own APIs and regional access.

Does it work on Raspberry Pi or ARM64?

You can build from source using Docker Compose on compatible Linux arm64 systems. The prebuilt GHCR image currently targets Linux amd64.
